# Private controller callback adapter

This default-unused adapter composes the existing getter routes with the callback scope policy for one owned controller. It does not create a native scope or install engine hooks. Call `player_callback_install` only after validating the executable, original table entries and targets. It initializes resident policy storage once, then publishes a single private 79-entry vtable with the two Itanium prefix entries. Slots 40, 41 and 43 dispatch through the policy; the caller may supply its independently validated slot-42 binding. Existing getter-only `player_routes_install` retains its interface and behavior. No published table is edited.

The embedding supplies `pcc_operations`: actual thread and identity checks, a scope observer, and open/close operations. A successful open must establish the owned P2 bank, singleton and zone together with `player_routes_enter`. A successful close must capture P2 getter answers, call `player_routes_leave`, and restore canonical state. These obligations must be implemented and verified by the embedding; stand-in operations here demonstrate the interface only. The policy allows a slot-43 callback to call slot 41 within the same scope without reopening it. Wrong thread, wrong controller, unauthorized reentry, or scope failure reports a fatal error; if the supplied fatal function returns, the wrapper calls `_Exit(126)` rather than returning to X4.

All storage and wrapper code must remain resident until the owner has established that no thread holds or can use the private vtable or callback pointer. `player_callback_restore` requires that quiescence and restores the stock controller vptr before native release; it does not prove quiescence. On uncertain installation or restoration the owner must retain obligations and discard the experiment rather than resume. Native callback thread provenance and exclusion of renderer, physics, input and other readers are not established by this adapter.

Run the focused fixture with `cc -UNDEBUG -std=c11 -O2 -Wall -Wextra -Werror src/native/engine/linux/test_player_controller_callback_adapter.c -o /tmp/x4-callback-adapter-test && /tmp/x4-callback-adapter-test`. It checks the composed table, stock getter forwarding in the owned scope, 43-to-41 nesting, scope reuse, wrong-thread fatal fallback and restoration. It neither loads nor runs the game.
